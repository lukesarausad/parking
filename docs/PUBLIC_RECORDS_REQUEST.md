## Draft Request Email

**To**: smc_pio@seattle.gov
**Subject**: Public Records Request - Parking Citation Data (Last 90 Days)

Dear Seattle Municipal Court Records Office,

Pursuant to the Washington Public Records Act (RCW 42.56), I am requesting the following public records:

### Records Requested

All parking citations issued within the City of Seattle for the period of **[DATE - 90 days ago] through [TODAY'S DATE]**.

### Requested Data Fields

For each citation, please include the following information (if available):

1. **Citation Number** (or unique identifier)
2. **Citation Date** (date issued)
3. **Citation Time** (time issued)
4. **Location** - any of the following:
   - Street address
   - Block/intersection
   - Latitude/Longitude coordinates
   - Blockface ID
5. **Violation Code** (e.g., SMC code)
6. **Violation Description** (e.g., "Expired Meter", "No Parking Zone")
7. **Fine Amount** (base fine, not including late fees)
8. **Neighborhood/District** (if categorized)
9. **Officer/Unit ID** (anonymized identifier is acceptable)

### Preferred Format

- CSV (comma-separated values) or Excel format
- If the dataset is large, a download link or FTP access is acceptable

### Purpose

This data will be used for:
- Public interest research on parking enforcement patterns
- Data visualization and analysis
- Non-commercial civic technology project

### Privacy Note

I understand that personally identifiable information (vehicle license plates, owner names, etc.) should be redacted. I am only requesting the citation metadata listed above.
